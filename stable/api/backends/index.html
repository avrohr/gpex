    Numerical backends

    GaussianProcess accepts a numerical backend through solver. linalg.DenseBackend() is the stateless default backend. Its prepare method returns a CholeskySystem containing the factorization and activity state for exact dense inference and fitting.

    Backend contract

    SolverConfiguration.prepare(system, ...) prepares an immutable LinearSystem. The input SymmetricLinearOperator supplies capacity, matmul, diagonal, and tiled materialize. Prepared systems provide solves, quadratic forms, log determinants, covariance and variance reductions, reusable projections, and append operations. These interfaces use numerical arrays and activity information rather than GP measurement types.

    For a prepared system, size is the active scalar count as a dynamic JAX integer, and capacity is the reserved scalar dimension as a static Python integer. Solves and projections accept full-capacity inputs. Activation increases size while preserving capacity. Input operators also expose capacity, and updates expose previous_capacity for the reserved dimension before activation.

    Custom backends inherit from eqx.Module and SolverConfiguration. Their prepared systems inherit from eqx.Module and LinearSystem. Both interfaces are abstract base classes, so subclasses must implement all abstract methods before they can be instantiated. Numerical inputs and update descriptions explicitly inherit the SymmetricLinearOperator and LinearSystemUpdate abstract base classes. Updates store their numerical system and newly active indices as fields.

    The small input interface keeps backends independent of kernels and observation types. Dense preparation requests materialization. The operator also supports products without storing the full matrix, ready for future iterative backends.

    CovarianceProjection is an abstract interface for reusable covariance reductions. The dense CholeskyProjection stores a whitened cross-covariance whose Gram matrix is the reduction. Diagonal and cross reductions let consumers reuse that state without accessing a backend's factorization.

    Likelihood objectives use the configured backend's quadratic_form and logdet. The dense quadratic form needs one triangular solve. Invalid factorizations propagate non-finite statistics so fitting can reject invalid trials. Backend configuration, prepared state, and returned results must support JAX transformations, with numerical arrays stored as dynamic PyTree leaves.

    Use configuration.prepare(system) to construct prepared state. For an already materialized matrix, use CholeskySystem.from_matrix(matrix, jitter=...). Factorization uses the symmetric part of the matrix with diagonal jitter. cholops owns this input symmetrization and the symmetry-preserving reverse rule.

    Dense systems store a cholops PaddedCholesky in factor. cholops owns factorization, numerical consumers, reserved-slot activation, and coefficient reuse. factor.order maps physical factor rows to canonical slots, and factor.inverse_order maps canonical slots back to physical rows. factor.factor exposes the lower-triangular array in physical order. solve and project accept canonical-order inputs. Preparing a system with active=mask reserves the inactive identity slots for append. Solves, quadratic forms, and projections ignore inactive input entries, including non-finite values. Solves return zero inactive coefficients. Generic systems without a mask are fully active. CholeskySystem(factor, tile_size) wraps an existing PaddedCholesky.

    def prepare(
    self,
    system: SymmetricLinearOperator,
    *,
    materialization_tile_size: int | None = None,
    active: Activity | None = None,
) -> CholeskySystem:
    """Prepare a factorization from a backend-neutral operator.

    If supplied, ``active`` identifies used rows. Inactive rows must be an
    independent identity system. They become reusable factor storage.
    Numerical consumers ignore inactive input entries. If no activity
    mask is supplied, every row is active.
    """
    matrix = system.materialize(tile_size=materialization_tile_size)
    if active is None:
        active = jnp.ones(system.capacity, dtype=bool)
    factor = PaddedCholesky.from_matrix(matrix, active=active)
    return CholeskySystem(factor, materialization_tile_size)

    @classmethod
def from_matrix(cls, matrix: SquareMatrix, jitter: float) -> CholeskySystem:
    """Factorize the symmetric part of a square matrix with diagonal jitter."""
    validate_jitter(jitter)
    matrix = jnp.asarray(matrix)
    if matrix.ndim != 2 or matrix.shape[0] != matrix.shape[1]:
        raise ValueError("matrix must be square")
    stabilized = matrix + jitter * jnp.eye(matrix.shape[0])
    factor = PaddedCholesky.from_matrix(
        stabilized, active=jnp.ones(matrix.shape[0], dtype=bool)
    )
    return cls(factor, None)

    def solve(
    self,
    right_hand_side: RightHandSide,
) -> RightHandSide:
    """Solve on active rows for vector or array RHS, including empty batches.

    Inactive input entries are ignored and inactive solution entries are zero.
    """
    right_hand_side = jnp.asarray(right_hand_side)
    if right_hand_side.ndim == 0 or right_hand_side.shape[0] != self.capacity:
        raise ValueError("right-hand side must start with the system capacity")
    shape = right_hand_side.shape
    columns = right_hand_side.reshape((self.capacity, -1))
    return self.factor.solve(columns).reshape(shape)

    def quadratic_form(self, right_hand_side: Vector) -> Scalar:
    """Return the active inverse quadratic form with one triangular solve.

    The vector has shape ``(capacity,)`` in canonical order. Supports JIT,

    def append(self, update: LinearSystemUpdate) -> CholeskySystem:
    """Activate reserved slots with a Schur-complement factor update."""
    cross, appended_covariance = self._trailing_blocks(update)
    with jax.default_matmul_precision("highest"):
        factor = self.factor.activate(update.indices, cross, appended_covariance)
    return eqx.tree_at(lambda s: s.factor, self, factor)

    def append_solve(
    self,
    update: LinearSystemUpdate,
    solution: Vector,
    right_hand_side: Vector,
) -> tuple[CholeskySystem, Vector]:
    """Activate reserved slots and reuse the existing coefficients.

    Inputs and outputs use canonical ordering. Old active RHS entries
    must be unchanged. Inactive inputs are ignored, and returned inactive
    coefficients are zero.
    """
    cross, appended_covariance = self._trailing_blocks(update)
    with jax.default_matmul_precision("highest"):
        factor, solution = self.factor.activate_solve(
            update.indices,
            cross,
            appended_covariance,
            solution=solution,
            rhs=right_hand_side,
        )
    return eqx.tree_at(lambda s: s.factor, self, factor), solution

    Moment assembly

    gpex.moments assembles prior means and covariances of linear functionals in canonical block order. These functions accept public blocks or reusable PreparedFunctionals from gpex.moments.measurements. Preparation groups compatible operators and retains activity and ordering information.

    assemble_covariance supports tiled evaluation while still returning the full dense matrix. assemble_covariance_diagonal evaluates only the diagonal. Inactive reserved entries are zero. These functions evaluate arrays and can be wrapped in an outer JIT with their consumers.

    def apply_covariance(
    blocks: Functionals,
    kernel: ScalarKernel,
    right_hand_side: FunctionalColumns,
    *,
    tile_size: int = 128,
) -> FunctionalColumns:
    """Apply latent covariance to canonical rows without constructing its matrix.

    Accept vectors or arrays with leading dimension equal to the scalar
    functional size. Inactive inputs are ignored and inactive outputs are zero.
    One operator output is indivisible and can exceed ``tile_size``. Pairwise
    tiles are recomputed in reverse mode, bounding working storage in both
    directions. Supports JIT, vmap, and differentiation of numerical inputs.
    General kernels still require quadratic pairwise work per application.
    """
    _validate_tile_size(tile_size)
    measurements = prepare_functionals(blocks)
    _validate_kernel_compatibility((measurements,), kernel)
    right_hand_side = jnp.asarray(right_hand_side)
    if right_hand_side.ndim == 0 or right_hand_side.shape[0] != measurements.size:
        raise ValueError("right-hand side must start with the functional size")
    shape = right_hand_side.shape
    columns = measurements.to_grouped(measurements.mask(right_hand_side)).reshape(
        (measurements.size, prod(shape[1:]))
    )
    layouts = tuple(
        _TileLayout.from_group(group, tile_size) for group in measurements.groups
    )
    inputs = []
    start = 0
    for layout in layouts:
        inputs.append(
            jnp.pad(
                columns[start : start + layout.size],
                ((0, layout.padded_size - layout.size), (0, 0)),
            )
        )
        start += layout.size
    parts = []
    for left in layouts:
        product = jnp.zeros((left.size, columns.shape[1]))
        for right, values in zip(layouts, inputs, strict=True):
            product = product + _apply_group_covariance(left, right, kernel, values)
        parts.append(product)
    result = measurements.to_canonical(jnp.concatenate(parts))
    return measurements.mask(result).reshape(shape)

    def assemble_mean(blocks: Functionals, mean: ScalarFunction) -> FlatMean:
    """Apply each functional to the mean and return canonical scalar ordering.

    Accept public blocks or prepared groups. Inactive reserved entries are zero.
    Supports JIT, vmap, and differentiation of numerical inputs.
    """
    measurements = prepare_functionals(blocks)

    def scalar_mean(point: Point) -> Scalar:
        value = jnp.asarray(mean(point))
        if value.ndim != 0:
            raise ValueError("mean functions must return a scalar")
        return value

    parts = [
        eqx.filter_vmap(lambda operator, point: operator.apply(scalar_mean, point))(
            group.operators, group.points
        ).reshape(-1)
        for group in measurements.groups
    ]
    return measurements.mask(measurements.to_canonical(jnp.concatenate(parts)))

    def assemble_covariance(
    left_blocks: Functionals,
    right_blocks: Functionals,
    kernel: ScalarKernel,
    *,
    tile_size: int | None = None,
) -> FlatCovariance:
    """Materialize covariance, optionally bounding pairwise working tiles.

    Tiles traverse numerical operator groups rather than public blocks. One
    operator output is never split. The final dense matrix is still allocated.
    With ``None``, each complete group pair is vectorized.
    """
    if tile_size is not None:
        _validate_tile_size(tile_size)
    left, right = prepare_functionals(left_blocks), prepare_functionals(right_blocks)
    if left.input_dimension != right.input_dimension:
        raise ValueError("covariance blocks must use the same input dimension")
    _validate_kernel_compatibility((left, right), kernel)
    rows = []
    for group in left.groups:
        row = jnp.concatenate(
            [
                _assemble_group_covariance(group, other, kernel, tile_size=tile_size)
                for other in right.groups
            ],
            axis=1,
        )
        if len(left.groups) > 1 or len(right.groups) > 1:
            # TODO: Remove this temporary compiler/driver workaround once the
            # mixed CUDA regression passes without it on the fixed toolchain.
            # JAX/jaxlib 0.10.2 on H100 with NVIDIA 615.71.09 can raise an illegal
            # address when fusing values/slopes/averages covariance assembly.
            # Separate completed rows from the final join. Barriers on each
            # individual pair instead expose another failure at smaller sizes.
            row = jax.lax.optimization_barrier(row)
        rows.append(row)
    covariance = left.to_canonical(jnp.concatenate(rows, axis=0))
    return left.mask(right.mask(right.to_canonical(covariance.T)).T)

    def assemble_covariance_diagonal(
    blocks: Functionals, kernel: ScalarKernel
) -> FlatVector:
    """Assemble the prior diagonal without allocating a full covariance."""
    measurements = prepare_functionals(blocks)
    _validate_kernel_compatibility((measurements,), kernel)
    parts = []
    for group in measurements.groups:
        components = prod(group.output_shape)

        def point_diagonal(operator, point, components=components):
            covariance = operator_covariance(
                kernel, operator, operator, x=point, y=point
            )
            return jnp.diag(covariance.reshape((components, components)))

        parts.append(
            eqx.filter_vmap(point_diagonal)(group.operators, group.points).reshape(-1)
        )
    return measurements.mask(measurements.to_canonical(jnp.concatenate(parts)))

    Covariance operator

    CovarianceSystem describes an observation covariance including block noise, jitter, and reserved inactive slots. Backends can consume it through the SymmetricLinearOperator interface:

    product = system.matmul(rhs, tile_size=128)
diagonal = system.diagonal()
matrix = system.materialize(tile_size=128)

    rhs has shape (capacity, *columns) in canonical order. Multiplication accumulates tiles directly and passes inactive inputs through as identity rows. The diagonal contains ones in inactive slots. This differs from prepared solve, which ignores inactive inputs. Tile widths count scalar outputs, but one operator output is indivisible. Tile size is static under JIT.

    Products support JIT, vmap, and numerical differentiation. Pairwise intermediates are recomputed in reverse mode so differentiation also avoids full covariance storage. General kernels still require quadratic pairwise work. Dense Cholesky remains the only backend, and likelihood evaluation remains exact.

    def matmul(
    self, right_hand_side: RightHandSide, *, tile_size: int = 128
) -> RightHandSide:
    """Apply covariance, noise, and jitter using bounded pairwise tiles.

    Inputs have shape ``(capacity, *columns)`` in canonical order. Inactive
    slots act as independent identity rows, unlike a prepared solve which
    ignores inactive inputs. Supports JIT, vmap, and differentiation.
    """
    right_hand_side = jnp.asarray(right_hand_side)
    covariance_product = apply_covariance(
        self.measurements, self.kernel, right_hand_side, tile_size=tile_size
    )
    shift = self.diagonal_shift().reshape(
        (-1,) + (1,) * (right_hand_side.ndim - 1)
    )
    return covariance_product + shift * right_hand_side

    def materialize(self, *, tile_size: int | None) -> SquareMatrix:
    covariance = assemble_covariance(
        self.measurements,
        self.measurements,
        self.kernel,
