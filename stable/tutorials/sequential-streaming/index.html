    Sequential observations¶

    Use posterior.append to add measurements to an existing posterior while reusing the work from conditioning. The GP parameters and measurement-error variance stay fixed between updates.

    Append observations¶

    The block argument selects the observation block to extend. New observations use that block's operator and measurement-error variance.

    append returns a new posterior. The original posterior and dataset remain unchanged.

    In [4]:
    Copied! 
    x_first = jnp.array([[-0.3]])
y_first = jnp.array([0.9])
after_first = initial.append(
    Locations(x_first), y_first, block="observed_values"
)
    x_first = jnp.array([[-0.3]]) y_first = jnp.array([0.9]) after_first = initial.append( Locations(x_first), y_first, block="observed_values" )
