    Kernels and means

    Built-in kernel families

    Standard kernels accept variance=1.0 and lengthscale=1.0 by default. variance is the covariance amplitude. A scalar lengthscale gives isotropic scaling, and a vector supplies one lengthscale per input coordinate (ARD).

    import jax.numpy as jnp
from gpex.kernels import RBFKernel, Matern52Kernel

isotropic = RBFKernel(variance=1.0, lengthscale=0.7)
ard = Matern52Kernel(variance=1.0, lengthscale=jnp.array([0.7, 1.2]))
    Class Kernel family Supported GP derivative order
    Matern12Kernel Matérn, ν = 1/2 0
    Matern32Kernel Matérn, ν = 3/2 1
    Matern52Kernel Matérn, ν = 5/2 2
    RBFKernel Squared exponential Any finite order

    All four families support callable posterior paths. Kernel sums and products, constructed with + and *, support conditioning, prediction, and finite-query sampling. They do not currently provide features for callable paths.

    Full input metrics

    The Generalized...Kernel variants of these four families accept a complete lower-triangular factor L with a positive diagonal. It defines the precision metric M = L @ L.T, with distance norm(L.T @ (x - y)):

    from gpex.kernels import GeneralizedMatern52Kernel

L = jnp.array([[1.4, 0.0], [0.3, 0.8]])
kernel = GeneralizedMatern52Kernel(variance=1.0, L=L)

    For a diagonal L, its diagonal entries are reciprocal lengthscales. L = jnp.diag(1 / jnp.array([0.7, 1.2])) reproduces the corresponding ARD metric. Generalized kernels also support callable paths.

    Plain numbers and arrays remain fixed during fitting. Use PositiveParameter for variance and lengthscales, or CholeskyParameter for L, to make them trainable. Read values through kernel.variance, kernel.lengthscales.lengthscale, or kernel.lengthscales.L. See Fitting hyperparameters and parameters and priors.

    Compose kernels and means

    Use + and * to compose kernels or means. For example, this two-dimensional model combines a trainable full input metric with a product of two fixed RBF kernels and a linear mean:

    from gpex import GaussianProcess
from gpex.kernels import GeneralizedRBFKernel
from gpex.means import ConstantMean, LinearMean
from gpex.parameters import CholeskyParameter
from gpex.parameters.priors import IndependentCholeskyPrior, LogNormalPrior, NormalPrior

factor = CholeskyParameter(
    jnp.array([[1.0, 0.0], [0.2, 1.4]]),
    prior=IndependentCholeskyPrior(
        diagonal_prior=LogNormalPrior(log_standard_deviation=0.5),
        off_diagonal_prior=NormalPrior(standard_deviation=0.4),
    ),
    name="precision_factor",
)
local = GeneralizedRBFKernel(variance=1.0, L=factor)
broad = RBFKernel(variance=0.3, lengthscale=2.0)
modulation = RBFKernel(lengthscale=jnp.array([1.5, 0.8]))
mean = LinearMean(weights=jnp.array([0.15, -0.1])) + ConstantMean(0.2)
gp = GaussianProcess(kernel=local + broad * modulation, mean=mean)

    Here only the precision factor is trainable. The kernel variances, fixed lengthscales, and mean coefficients remain fixed.

    Extension interfaces

    A Kernel maps two points of shape (d,) to a scalar covariance. A Mean maps one point to a scalar mean. Both are Equinox modules. Custom kernels must be positive semidefinite and declare max_derivative_order when the latent GP has finite smoothness. Evaluation must support the JAX transformations required by the chosen operators, including derivatives at coincident inputs.

    RadialKernel supplies input scaling and evaluation from squared distance. Subclasses define _correlation and _derivative_order. RadialFeatureKernel also requires _sample_frequencies for its unit-scale correlation.

    SeparableKernel.factorization(input_dimension) returns a KernelFactorization(coefficient, factors). Each factor is a scalar-coordinate kernel, and their product times the coefficient must equal the kernel and its derivatives. Derive factors from current parameter values. Factors with array state should be Equinox modules. This interface enables factored tensor quadrature. Pass the kernel object directly to GaussianProcess to expose this capability.

    FeatureKernel.random_features returns a fixed callable mapping one point to a feature vector. Feature inner products approximate the complete kernel, including its variance. Store random draws as array fields so repeated calls use the same features and the map can cross JIT boundaries. Exact finite feature maps are supported as well. See the class contracts below.

    def random_features(
    self,
    key: PRNGKeyArray,
    input_dimension: int,
    *,
    feature_count: int = 1024,
) -> Callable[[Point], Array]:
    """Construct Fourier features; see
    [`FeatureKernel.random_features`][gpex.kernels.FeatureKernel.random_features].
    """
    if (
        isinstance(feature_count, bool)
        or not isinstance(feature_count, int)
        or feature_count < 1
    ):
        raise ValueError("feature_count must be a positive integer")
    if (
        isinstance(input_dimension, bool)
        or not isinstance(input_dimension, int)
        or input_dimension < 1
    ):
        raise ValueError("input_dimension must be a positive integer")
    self.lengthscales.validate_dimension(input_dimension)
    frequency_key, phase_key = jax.random.split(key)
    frequencies = self.lengthscales.transform_frequencies(
        self._sample_frequencies(frequency_key, (feature_count, input_dimension))
    )
    phases = jax.random.uniform(
        phase_key, (feature_count,), minval=0.0, maxval=2.0 * jnp.pi
    )
    return _FourierFeatures(
        frequencies, phases, jnp.sqrt(2.0 * self.variance / feature_count)
    )

    coefficient is a scalar array, and factors contains one scalar two-argument callable per input coordinate, in coordinate order. Factors need not be stationary. Their numerical state must remain dynamic PyTree leaves and their evaluation must support JAX transformations.

    def __init__(
    self,
    weights: Parameter | MeanWeights,
    intercept: Parameter | Scalar | float = 0.0,
) -> None:
    weights = weights if isinstance(weights, Parameter) else jnp.asarray(weights)
    weights_value = weights.value if isinstance(weights, Parameter) else weights
    if weights_value.ndim != 1 or weights_value.size == 0:
        raise ValueError("linear-mean weights must be a nonempty vector")

    intercept = (
        intercept if isinstance(intercept, Parameter) else jnp.asarray(intercept)
    )
    intercept_value = (
        intercept.value if isinstance(intercept, Parameter) else intercept
    )
    if intercept_value.ndim != 0:
        raise ValueError("linear-mean intercept must be scalar")
    self.weights_parameter = weights
    self.intercept_parameter = intercept
